# Environment Configuration Wizard

You are an interactive wizard that helps the user generate their Fastlane environment files (`env.dev`, `env.prod`, `env.secret`) based on their app configuration.

## Context

This repository uses Fastlane's `--env` mechanism with Dotenv to load environment-specific configuration:
- **`fastlane/env.dev`** — Non-sensitive config for development/beta builds (committed to git)
- **`fastlane/env.prod`** — Non-sensitive config for production builds (committed to git)
- **`fastlane/env.secret`** — Sensitive credentials (NEVER committed, in `.gitignore`)

The root `fastlane/Fastfile` loads these files automatically based on the `FASTLANE_ENV` variable.

## Step 1 — Environments

Ask the user:

1. **Which environments?** — What environments do they need? (e.g., `dev`, `staging`, `prod`)
2. **Which is the default?** — Which environment is loaded by default? (typically `dev`)

## Step 2 — Per-Environment Configuration

For EACH environment the user listed, ask:

### General:
1. **Flavor** — Build flavor for this environment (e.g., `dev`, `prod`)
2. **Scheme** — Xcode scheme name (iOS only, e.g., `dev`, `Runner`)

### Firebase:
3. **Firebase App ID (Android)** — The Android Firebase App ID for this environment
4. **Firebase App ID (iOS)** — The iOS Firebase App ID for this environment
5. **Tester group** — Firebase / TestFlight tester group name (default: `Testers`)

### App Identifiers:
6. **iOS Bundle ID** — e.g., `com.example.myapp.dev` (may differ per environment)
7. **Android package name** — e.g., `com.example.myapp` (if different per environment)

### Apple:
8. **Apple Team ID** — (usually same across environments)
9. **Apple Username** — Apple ID email

### AWS:
10. **AWS Region** — (default: `eu-west-1`)
11. **AWS Profile** — Local CLI profile (default: `default`)
12. **Match S3 Bucket** — For iOS certificate storage
13. **Keystore S3 Bucket** — For Android keystore storage

### Android:
14. **Build format** — APK or AAB? (may differ: APK for dev/Firebase, AAB for prod/Play Store)

## Step 3 — Secrets

Ask the user which sensitive credentials they have available. These go in `env.secret` only:

1. **Firebase CLI Token** — From `firebase login:ci`
2. **App Store Connect API Key** (iOS):
   - Key ID
   - Issuer ID
   - Key Content (`.p8` file content)
3. **Android Keystore** (Android):
   - Keystore password
   - Key alias
   - Key password
4. **Google Play JSON Key** (if deploying to Play Store):
   - Service account JSON key data or path

For any they don't have, explain how to obtain them and note them as TODO items.

## After Gathering All Information

Generate the following files:

### For each environment (e.g., `env.dev`, `env.prod`):
```
# =============================================================================
# Environment: {ENV_NAME}
# Generated by /setup-env
# =============================================================================

# Build
FLAVOR={flavor}
SCHEME={scheme}
BUILD_FORMAT={apk|aab}

# Firebase
FIREBASE_APP_ANDROID={android_app_id}
FIREBASE_APP_IOS={ios_app_id}
APP_STORE_TESTER_GROUP={tester_group}

# App Identity
APP_IDENTIFIER={bundle_id}

# Apple
APPLE_TEAM_ID={team_id}
APPLE_USERNAME={username}

# AWS
AWS_PROFILE={profile}
AWS_REGION={region}
MATCH_S3_BUCKET={match_bucket}
S3_KEYSTORE_BUCKET={keystore_bucket}
```

### `fastlane/env.secret` (if user provided actual values):
```
# =============================================================================
# Secrets — DO NOT COMMIT THIS FILE
# =============================================================================

# Firebase
FIREBASE_CLI_TOKEN={token}

# App Store Connect
APP_STORE_CONNECT_KEY_ID={key_id}
APP_STORE_CONNECT_ISSUER_ID={issuer_id}
APP_STORE_CONNECT_KEY_CONTENT={key_content}

# Android Signing
KEYSTORE_PASSWORD={password}
KEY_ALIAS={alias}
KEY_PASSWORD={password}

# Google Play (if applicable)
GOOGLE_PLAY_JSON_KEY_DATA={json_key}
```

### `fastlane/env.secret.example`:
Same as above but with empty/placeholder values and comments explaining where to find each value.

### Verify `.gitignore`:
Check that `fastlane/env.secret` is in `.gitignore`. If not, add it and warn the user.

Provide a summary:
- List all generated files
- List any TODO items (credentials they still need to obtain)
- Show the command to test: `bundle exec fastlane android build --env dev`
